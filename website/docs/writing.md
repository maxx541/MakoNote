# 寫作與編輯器

![編輯器](/img/shots/editor.webp)

## 方塊編輯器

在空行輸入 <kbd>/</kbd> 叫出方塊選單：標題、清單、摺疊清單、引用、提示框、程式碼、表格、圖片、影片、書籤連結，以及 MakoNote 專屬的「插入遊戲台詞」與「時數統計表」。

![斜線選單](/img/shots/slash.webp)

- 選取文字會出現格式工具列：段落類型、粗體、顏色、對齊、連結，也能「連結到段落」，閱讀時點了會捲到那一段。
- 按右鍵有常用動作，內容可以在 設定 → 撰寫 自訂。
- <kbd>Ctrl</kbd> + <kbd>Z</kbd> 復原，連文章屬性（狀態、作品、標題）的修改也在同一條時間線上。

## 智能分段

一般的編輯器按 <kbd>Enter</kbd> 就切出新的文字塊，貼上一段有換行的文字也會被切碎。MakoNote 用「句尾符號」判斷一段話結束了沒：

| 情況 | 結果 |
|---|---|
| 句子還沒結束（沒有句號、問號、驚嘆號…）按 <kbd>Enter</kbd> | 只換行，留在同一個文字塊 |
| 句子結束後按 <kbd>Enter</kbd> | 開新的文字塊 |
| 連按兩次 <kbd>Enter</kbd>，或 <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | 一定開新的文字塊 |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | 永遠只換行 |
| 貼上多行純文字（PDF、文字檔） | 依句尾符號接回完整段落 |

已經被切碎的文章，打開「智能分段」面板，按「整理」就會一次併回去（會先告訴你幾個文字塊會併成幾個，不滿意按 <kbd>Ctrl</kbd> + <kbd>Z</kbd>）。句尾符號可以自訂。

![智能分段與版面面板](/img/shots/smart.webp)

## 撰寫時間

只在視窗位於前景、而且最近有輸入時計時；閒置超過設定的時間就暫停。完工後計時也會暫停，真的再修改內文才繼續。
