# 發佈到各平台

同一篇心得，編輯頁上方的分頁可以直接看成不同平台的格式：

| 分頁 | 內容 |
|---|---|
| Markdown | 乾淨的 Markdown，可以貼到任何支援的地方 |
| 巴哈 | 巴哈姆特小屋的 BBCode，左邊原始碼、右邊預覽；圖片可設大中小、相鄰兩張併排 |
| FB | 純文字，圖片標成〔圖1〕〔圖2〕，依順序上傳 |
| 串文 | 依字數自動拆成多則，適合 Threads、X、Bluesky；可以拖曳調整每則的內容 |
| Google 文件 | 複製後到 Google 文件貼上，標題、粗體、顏色、置中、圖片都會保留 |

![巴哈格式預覽](/img/shots/baha.webp)

點分頁只是預覽；在某個格式裡修改後，才會另外存成那個格式的版本，主稿不受影響。主稿之後有更新時，版本頁會提醒你。

## 圖片上雲端（選用）

巴哈等網站看不到你電腦裡的圖片。在 設定 → 雲端 填入自己的 Cloudinary 金鑰後，文章屬性的「雲端」可以上傳這篇用到的圖片，再一鍵把巴哈、Markdown 版本的圖片換成雲端網址。

- 只上傳有變動的檔案；雲端上的顯示名稱是「標題_圖1」「標題_圖2」。
- API secret 只加密存在這台電腦，不寫進文章庫。
- 換電腦時可以從雲端把文章和圖片完整還原回資料夾。
