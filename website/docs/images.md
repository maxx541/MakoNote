# 圖片與影片

## 放圖片

貼上、從檔案總管拖進來、或用 <kbd>/</kbd> 圖片插入都可以。圖片會壓縮成 WebP 存進這篇的 `assets/`，從網頁複製來的圖也會自動下載到本機。

一次放多張會**自動併排**（每排最多 4 張，等高縮放）。

## 併排與圖文並排

- 抓住段落左邊的長條把手，把圖片拖到另一張圖、或同一排的左右側，出現插入線就放開。
- 拖到**有字的段落**左右側，就變成圖文並排。
- 兩張圖之間、圖和文字之間都有分隔線，可以拖曳調整大小；接近同大小時會吸附，再拉才脫離。
- 在圖上按右鍵有「與下一張圖併排」「拆開併排」「與下一段文字並排」。

## 影片

貼上單獨一個 YouTube（含 Shorts）或 bilibili 網址，會變成可以直接播放的內嵌播放器。拖右下角等比例縮放，可以切換 16:9、4:3、1:1、9:16。
