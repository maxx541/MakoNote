# 外觀與快捷鍵

## 邊寫邊調版面

編輯頁右上的「版面」會在右邊開一個面板，不蓋住文章：字型、字級、行距、編輯區寬度、背景圖、遮罩、模糊、面板透明度、圓角、主色，改了立刻看得到。

- 編輯頁的背景預設用這篇的作品封面，並且跟著文章一起捲動。
- 外觀可以存成主題（`.app/themes/`），帶到別台電腦。
- 小貼圖：指定一個圖片資料夾，畫面角落會隨機出現一張，蓋到內容時自動藏起來。

## 快捷鍵

| 按鍵 | 作用 |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | 搜尋整個文章庫 |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | 收起／展開側邊欄 |
| <kbd>Ctrl</kbd> + 滾輪、<kbd>Ctrl</kbd> + <kbd>+</kbd> / <kbd>-</kbd> | 整個介面縮放 |
| <kbd>Ctrl</kbd> + <kbd>0</kbd> | 縮放還原 |
| <kbd>/</kbd> | 方塊選單 |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | 開新的文字塊 |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | 同一個文字塊裡換行 |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> ／ <kbd>Ctrl</kbd> + <kbd>Y</kbd> | 復原／重做 |
