# 快速開始

MakoNote 是專為 Galgame 與動畫愛好者設計的筆記軟體，也是以作品為中心的文章管理與展示系統：每一篇文章都連結到一部作品，從作品頁就能看到它的全部。

## 安裝

1. 下載 `MakoNote-x.y.z-portable.exe`（Windows 10／11，64 位元）。
2. 直接雙擊執行，不用安裝。第一次啟動要解壓縮，會比之後慢幾秒。

## 選一個資料夾當文章庫

第一次打開時選一個資料夾。之後所有文章都以普通檔案存在這裡：

- 一篇文章一個資料夾，內文是 Markdown，圖片放在旁邊的 `assets/`。
- 不開 MakoNote，用記事本、VS Code、Obsidian 也讀得到。
- 已經有巴哈小屋爬蟲備份或 Anytype 匯出的資料夾，可以直接選它，MakoNote 會認得。

## 寫第一篇

按右上的「新增文章」，寫完按「完工」。完工會記下完工日，以及這篇實際花了多少撰寫時間（只算視窗在前景、而且有在輸入的時間）。

:::tip
畫面上不放操作說明。忘了怎麼用，按標題列右上的「？」就能打開使用說明。
:::
