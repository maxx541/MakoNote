# 遊戲台詞辨識

寫心得最常做的事之一，就是引用遊戲裡的台詞。MakoNote 讓你直接丟截圖。

![插入遊戲台詞](/img/shots/ocr.webp)

1. 輸入 <kbd>/</kbd> 台詞，或在編輯區按右鍵選「插入遊戲台詞」。
2. 選、貼上或拖入一到多張截圖，縮圖上可以調整順序。
3. 選辨識語言（日文、繁體中文、英文），按「辨識」。
4. 結果可以直接修改，按「以引用插入」。

辨識用的是 Windows 內建的 OCR，**截圖不會上傳到任何地方**。

## 去掉介面文字

截圖裡常會混進遊戲介面的字。MakoNote 內建一份排除表：隨機抽 26 款 galgame 的截圖辨識，找出跨遊戲重複出現的介面字（SAVE、LOAD、AUTO、SKIP、LOG、HISTORY、返回前個畫面、存檔、セーブ…），再補上常見的同義字。

- 英文要整個單字相符才拿掉，並容忍 OCR 把字母拆開或看錯（`S A V E`、`H1st0ry`）。
- 中日文要整行都是介面字才拿掉，4 個字以上的詞才會從行內拿掉，不會誤傷台詞。
- 另外可以加自己的忽略字詞（例如角色名牌）。

:::tip 什麼截圖辨識得最好
遊戲的「歷史紀錄／Backlog」畫面字多、背景單純，辨識結果最乾淨。
:::
