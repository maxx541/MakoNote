# 常見問題

### 支援哪些系統？

Windows 10／11（64 位元）。台詞辨識用的是 Windows 內建 OCR；要辨識日文，Windows 需要安裝日文語言套件的「光學字元辨識」。

### 資料存在哪裡？

全部在你選的文章庫資料夾。MakoNote 自己只在使用者資料夾記一個設定檔（文章庫位置、Cloudinary 金鑰）。沒有帳號、不需要連網；只有搜尋作品資料、抓封面、上傳雲端時才會連線。

### 可以和 Obsidian、Typora 一起用嗎？

可以。文章就是 Markdown，同一個資料夾可以同時用不同軟體打開。

### 已經有巴哈小屋的文章備份？

把那個資料夾選成文章庫即可。MakoNote 認得巴哈小屋爬蟲輸出的 `article.md` 與原始排版 `content.html`，打開時會還原巴哈原文的置中、顏色、表格與圖片。也認得 Anytype 匯出的 Markdown。

### 換電腦怎麼辦？

把整個文章庫資料夾複製過去就好。用了 Cloudinary 的話，也可以在 設定 → 雲端 從雲端還原。
