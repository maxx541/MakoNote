# 書架與作品

![Galgame 書架](/img/shots/shelf.webp)

## 三種模式

- **Galgame**、**動畫**：依文章的「主題」分類，連結到該類作品的心得也會一起出現（例如聖地巡禮遊記連結了某款遊戲，就會出現在 Galgame 書架）。
- **部落格**：所有文章依時間排列。

左邊的資料夾樹永遠顯示整個文章庫，不受模式影響。

## 作品資料

寫文章時按「連結作品」，從 VNDB（遊戲）或 Bangumi（動畫）搜尋，封面、品牌、發售日會自動帶進來。書架上方的「配對作品」可以一次幫很多篇配對。

點作品進入作品頁，可以看到這部作品的所有心得、總撰寫時間，也能：

- **更換封面**：按按鈕選圖，或直接把圖片拖到橫幅上。
- **重新配對**：作品配錯時，搜尋正確的作品，勾選的心得會改連過去。

![作品頁](/img/shots/game.webp)

## 找文章

- <kbd>Ctrl</kbd> + <kbd>K</kbd> 模糊搜尋整個文章庫：標題、作品名（含羅馬拼音與中文名）、標籤、內文。
- 「篩選」可以依狀態、主題、作品、資料夾、字數組合條件，存成「動態收藏」後會自動更新。
- 把文章卡片拖到左邊的資料夾，就會實際搬移檔案。
