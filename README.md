# MakoNote

專為 Galgame 與動畫愛好者設計的筆記軟體（Windows）。以作品為中心的文章管理與展示系統：每一篇文章都連結到一部作品，從作品頁就能看到它的全部。

第一次打開會跳出使用說明，之後按標題列右上的「？」就能再看。

## 使用

- 直接執行打包好的 `MakoNote-portable.exe`（免安裝，單一檔案），到 [Releases](https://github.com/maxx541/MakoNote/releases/latest) 下載；介紹與使用說明在 https://maxx541.github.io/MakoNote/
- 或從原始碼：在這個資料夾執行 `npm install`，之後雙擊 `啟動.bat`，或 `npm start`；改程式碼要即時更新用 `npm run dev`。
- 打包成 exe：`npm run pack`，輸出在專案旁邊的 `MakoNote-release` 資料夾。
- 介紹網站（Docusaurus）在 `website/`：`cd website`，`npm install` 後 `npm start` 開發、`npm run build` 輸出靜態網站到 `website/build`。首頁在 `src/pages/index.js`，使用說明在 `docs/`，產品截圖在 `static/img/shots/`，下載連結在 `src/constants.js`。

## 核心原則：資料夾就是資料庫

- **所有內容都是普通檔案**。文章是 Markdown（`.md`），屬性寫在檔案開頭的 front matter，圖片放在文章旁邊。不用這個程式時，用記事本、VS Code、Obsidian 都打得開。
- **直接讀寫原資料夾，不複製**。文章庫可以指向任何資料夾（設定 → 文章庫 → 切換文章庫）。
- **只打開來看不會改檔**。只有在程式裡真的修改內容，才會寫回檔案。
- 文章庫位置以設定檔為準：程式開著時換了母資料夾，再開一次程式或視窗取得焦點就會切換過去，不會停在啟動時的舊資料夾。
- 程式自己的東西只放兩個地方：文章庫裡的 `.app/`（設定、背景圖、主題）和 `_works/`（作品資料與封面）。刪掉它們不影響任何文章。

### 認得哪些格式

| 來源 | 樣子 | 讀進來的方式 |
|---|---|---|
| 本程式建立 | `標題/article.md` + `assets/` | 原生格式 |
| 巴哈小屋爬蟲 | `日期_標題/article.md` + `content.html` + `images/` | 開頭的「分類、發表時間、原文、標籤」自動變成屬性，狀態為「完成」。排版從 `content.html` 還原：置中、靠右、文字顏色、小標題、刪除線、表格（例如時數統計）都跟巴哈原文一致 |
| Anytype 匯出 | `某某.md` + `files/` + `schemas/` | `Name`、`Creation date`、`Object type` 變成標題、建立時間、主題；反斜線圖片路徑照樣顯示 |

規則：資料夾裡有 `article.md` 就是一篇；沒有子文章、但有 `.md` 的資料夾，每個 `.md` 各是一篇；有子文章的資料夾是分類資料夾，裡面零散的 `.md`（例如目錄清單）不當文章。

匯入的文章第一次在程式裡修改並存檔時，開頭會改寫成統一的 front matter（原本的資訊都保留在欄位裡，例如巴哈原文網址存在 `source`）。

### 文章檔案長這樣

```markdown
---
id: 20261101-a3f9
title: 終のステラ 劇情文章
status: 撰寫中            # 撰寫中 / 完成
topic: Galgame
tags: [推坑, Key社]
works: [bgm304421]        # 連結的作品：VNDB 是 v 開頭、Bangumi 是 bgm 開頭、自建是 custom- 開頭
created: 2026-10-28 20:00 # 建立時自動寫入
updated: 2026-11-01 14:06
completed: 2026-11-01 14:06
active_seconds: 2400      # 實際撰寫秒數
---

正文……
```

- **摺疊清單**存成 `<details><summary>標題</summary> … </details>`，GitHub 和 Obsidian 也會顯示成可摺疊。
- **置中、靠右、文字顏色**：Markdown 沒有這些，所以只有這種段落會存成一行 HTML，例如 `<p align="center"><span style="color:#1d267e">文字</span></p>`，保留原始色碼。GitHub、Obsidian 看得懂置中。其他段落都是一般 Markdown。
- **段落連結**：被連結的段落尾端會加 `^錨點`，連結寫成 `[文字](#^錨點)`，和 Obsidian 的段落連結同一套寫法。只有真的被連結的段落才會出現錨點。
- **併排圖片**：同一行連續的圖片語法 `![](assets/img-01.webp) ![](assets/img-02.webp)`，別的軟體會顯示成並排或連續的圖。
- **內嵌影片**（YouTube、bilibili）：獨立一行的連結加註解標記，`[YouTube 影片](https://www.youtube.com/watch?v=…) <!-- makonote:video {"width":640} -->`。註解在別的軟體看不到，連結照樣能點。
- **書籤連結**：`[網頁標題](https://…) <!-- makonote:bookmark {"desc":"…"} -->`。
- **提示框（Callout）**：GitHub／Obsidian 的寫法 `> [!NOTE]`、`> [!WARNING]`……下一行起是 `> 內容`。

## 功能

**作品與文章**
- 三種模式：**Galgame**、**動畫**、**部落格**。
  - Galgame 與動畫是作品封面牆。封面下的色條代表文章篇數與狀態（綠＝完成、橘＝撰寫中）。單擊在右側展開這部作品的所有文章，雙擊進入詳細頁。還沒連結作品的文章用自己的圖獨立上架：優先用文章屬性的 `cover`（巴哈文章的封面已經下載成文章資料夾裡的 cover 圖），沒有的話用內文第一張圖。
  - 兩個模式收兩種文章：「主題」屬於它的（主題含 `gal` → Galgame；主題含「動畫」或 `anime` → 動畫；巴哈的分類、Anytype 的物件類型都是主題），以及**連結到該類作品**的（連到遊戲的也算 Galgame、連到動畫的也算動畫，例如主題是「旅遊」但連到遊戲的聖地巡禮文章）。判斷不準就改文章的主題或作品連結，沒有別的隱藏規則（不看標籤、標題）。
  - 側欄的數量、主題、標籤與篩選條件都跟著目前模式走。
  - 部落格模式：左邊縮圖、右邊摘要，顯示全部文章（不分主題）。
- 上方「繼續撰寫」列出最近在寫的文章。
- 整個介面縮放：Ctrl＋滾輪、Ctrl＋加號／減號、Ctrl＋0 還原（50%～250%，版面和字體一起等比例變，記在這台電腦上）。
- 圖片到處都能貼上、拖進來：編輯區（一次多張自動併排）、插入台詞的辨識視窗、文章的封面欄、作品頁的橫幅（直接換封面）、設定的背景圖。拖著圖片經過會出現虛線框；貼上要先把滑鼠停在那個區域。
- 模糊搜尋（Ctrl+K）：標題、作品名（含羅馬拼音、中文名、別名）、品牌、標籤、內文都會搜，打錯字也找得到。搜尋永遠從文章庫根目錄的全部文章找，不受 Galgame／動畫／部落格模式限制（模式只用來分類作品牆）。
- 篩選與動態收藏可以加「字數」條件（大於、小於、介於）；排序可以依字數。字數：中文、日文、韓文每字算 1，英文與數字每個單字算 1，Markdown 標記、圖片、網址、註解不算。部落格列表與右側面板會顯示字數。
- 左側：狀態、動態收藏（存起來的篩選條件，會自動更新）、資料夾樹（把文章拖到資料夾上就會實際搬移）、主題、標籤。資料夾樹與各資料夾的篇數永遠反映整個文章庫，不受 Galgame／動畫／部落格模式影響；點資料夾會列出裡面的全部文章。狀態、主題、標籤、動態收藏仍依目前模式統計。四個區塊都可以點標題收合；資料夾樹裡有子資料夾的節點有箭頭可以單獨收合（收合的資料夾本身仍可選取、可接住拖來的文章）。收合狀態會記在設定裡。標題列左邊的側邊欄按鈕（或 Ctrl+B）可以把整個側邊欄往左收起來、再按一次拉出來，原本的區塊與資料夾收合狀態不受影響。

**作品資料**
- 連結作品：從 VNDB（視覺小說）或 Bangumi（遊戲、動畫、書籍）搜尋，也可以自己建立。封面和資料會下載到 `_works/`，之後不需要網路。
- **批次配對作品**（Galgame、動畫模式右上的「配對作品」；部落格模式沒有）：用標題裡的《作品名》一次搜尋目前模式裡還沒連結、或連結的類型不對的文章。
  - Galgame 模式只配遊戲，可選 VNDB 或 Bangumi（遊戲）；動畫模式只配 Bangumi 的動畫。
  - 比對時會統一繁簡（Bangumi 多半是簡體），依名稱相似度排序；標題沒有《》時取空白前的部分，並去掉「簡評、文章」等字。純數字的片段、樣片或預告這類條目不會被當成本片。
  - 日文原名和中文標題字面對不上的（例如《初雪櫻》↔ はつゆきさくら）找不到有把握的，會留給你手動選。
  - 有把握的才預先打勾，按「套用」才寫入。寫入時只在文章開頭的屬性加上作品編號，正文一個字都不動，巴哈文章的原始排版照樣保留。
- 作品詳細頁或右鍵選單可以更換成自己的封面，原本的封面保留，可以隨時還原。
- 作品詳細頁的「重新配對」：這部作品配錯時，選資料來源（VNDB／Bangumi 遊戲／Bangumi 動畫）重新搜尋，選好正確的作品，勾選要改的文章，就會把這幾篇的作品編號換成新的（只改開頭屬性，正文與其他作品連結不動）。

**編輯器**
- 方塊式編輯，按 `/` 叫出選單，仿 Anytype／Notion 分組：
  - MakoNote：插入遊戲台詞、時數統計表
  - 文字：文字、標題、子標題、小標題、引用、Callout 提示框、程式碼
  - 列表：Checkbox 核取方塊、項目清單、編號清單、Toggle 折疊清單、折疊標題（三種大小）
  - 媒體：圖片（可多選、可直接併排）、併排圖片、Video 影片（YouTube／bilibili 內嵌，或本機影片檔）、Audio 音訊、檔案、書籤連結
  - 其他：分隔線、表格、表情符號
- 編輯區最大寬度預設 760px（原本的樣子），可在 設定 → 文字，或編輯頁右上的「版面」面板改成 900～1600px 或滿版。巴哈、FB 等格式預覽仍用各平台原本的寬度。
- **復原／重做**：Ctrl+Z、Ctrl+Y（或 Ctrl+Shift+Z）。打開文章後直接按 Ctrl+Z 不會把內容清掉。焦點不在文字框時（例如剛點了狀態、解除作品連結），按 Ctrl+Z 會復原最近的那一步，屬性與內文排在同一條時間線上。標題、主題、標籤這些輸入框裡用的是輸入框自己的復原。
- **圖片併排**（一排最多 4 張；單張圖預設最寬 420px、一排約每張 300px，參考 Anytype 的大小）：
  - 把一張圖（拖左邊的 ⋮⋮ 長條把手）拖到另一張圖或同一排的左側或右側（包含圖片旁邊的空白處），出現藍色插入線就放開，圖片會插在那個位置併排；併排裡的圖可以直接拖出來放到別段，或拖到別排。
  - 右鍵「與下一張圖併排」「拆開併排」；滑到併排的圖上有左移、右移、移出併排、刪除。
  - 一次選多張、貼上多張、或從檔案總管一次拖進多張圖片，會自動併排（每排最多 4 張，超過接到下一排）；要分開放，在圖上按右鍵選「拆開併排」。
  - 併排裡每張圖可以獨立調大小：拖兩張之間的分隔線，只改這兩張，整排總寬不變；兩張接近同高或同寬時會吸附（分隔線變亮），再拉才脫離，拉回預設的等高就不另外存。大小存在圖片語法的標題裡（`![](a.webp "w=1.29")`），別的 Markdown 軟體只當成提示文字。
  - 轉巴哈時整排放進同一個 `[div]`，每張的 width 依比例換算，整排控制在 740px 內（巴哈內文約 760px）。
- **文字和圖片併排**（Anytype 的欄位）：把一張圖拖到有字的段落左側或右側（出現插入線就放開），圖片會在那段文字旁邊；中間的分隔線可以拖曳調整圖片佔多寬（接近對半會吸附）；滑到圖上有換邊、拆開（圖放到文字下面）、刪除圖片。也可以在單張圖上按右鍵選「與下一段文字並排（圖在左／右）」。存成一行：`文字… ![](a.webp "side=right;w=0.4")`（圖在左就是 `![](a.webp "side=left;w=0.4") 文字…`），轉巴哈、FB 等沒有圖文並排的格式時變成文字加圖片。
- **智能分段**（編輯列的「智能分段」按鈕）：用「句尾符號」判斷一段話結束了沒，句尾符號可以自訂（預設 。！？!?…⋯.，後面接 」』） 也算結束）。
  - 按 Enter：這句話還沒結束（沒有句尾符號）就只換行、留在同一個文字塊；有句尾符號才開新文字塊。連按兩次 Enter、或 Ctrl+Enter 一定開新的；Shift+Enter 永遠只換行。只作用在一般段落，標題、清單、引用、程式碼維持原本的 Enter；輸入法選字時的 Enter 不受影響。
  - 貼上多行純文字：依句尾符號重新分段，被硬換行切碎的文字（PDF、文字檔）接回完整段落；整段都沒有句尾符號時（像清單）維持原本的貼上。從網頁貼上有連結、圖片、表格、清單的內容不動。
  - 整理已經被切碎的文字塊：面板會先告訴你「選取的 N 個方塊會併成 M 個」，按下去一次完成，Ctrl+Z 可以復原。沒選東西就整理整篇。併段時可選「直接接起來」（英文單字之間補空白）或「保留成同段換行」。只併一般段落，標題、圖片、清單不動。
- **內嵌影片**：貼上單獨一個 YouTube（watch、youtu.be、Shorts）或 bilibili（BV 號，可帶 `?p=` 分 P）網址到空白段落就變成播放器，不要的話按 Ctrl+Z 變回連結。拖右下角是整體等比例縮放（預設 16:9，Shorts 9:16，可以改比例），最寬不超過編輯欄。連線時直接顯示 YouTube／bilibili 自己的預覽畫面（有標題和播放鍵）；離線時只顯示連結。巴哈原文裡內嵌的 YouTube 也會讀成播放器。轉巴哈、FB、串文時變成影片網址。
- 內建「影片」方塊的「嵌入」分頁貼了 YouTube／B 站網址，也會自動換成播放器（內建的 `<video>` 播不了這兩家）。
- 「插入遊戲台詞」：選（或直接 Ctrl+V 貼上）一到多張截圖，整張用 Windows 內建 OCR 辨識文字，依縮圖上的順序（可以左右移動）接起來，再以引用插入。沒有裁切、沒有角色名判斷，就是讀字再合併。
  - 合併方式：每張截圖合成一行（預設），或照辨識出來的分行。
  - 內建排除表：預設套用，把遊戲介面常見字（SAVE、LOAD、Q.SAVE、AUTO、SKIP、LOG、HISTORY、JUMP、SCENE JUMP、BACK、RETURN、TITLE、REPEAT、VOICE、返回前個畫面、語音書籤、退出遊戲、保存進度、存檔、快進、オート、スキップ、セーブ、ロード…）拿掉。來源是隨機抽 26 款 galgame 的截圖各 5 張辨識，挑出跨遊戲重複出現的介面字，再補各家常見同義字（`src/lib/ocrIgnore.js`）。英文整個單字才算、容忍 OCR 把字母拆開或看錯（S A V E、H1st0ry）；中日文整行只有這個字才拿掉，4 個字以上的行內出現也拿掉，所以不會誤傷台詞。可以取消勾選，也可以展開看完整清單。
  - 自己加的忽略字詞：一行一個，辨識結果裡出現就拿掉（例如遊戲介面的 AUTO、SKIP、LOG，或不想要的角色名）；拿掉後變空的行整行丟掉。會記住，下次還在。
  - 換順序、改忽略字詞、改合併方式，結果立刻重排（不用重新辨識）；結果欄可以直接修改。圖片不會上傳到任何地方。
- 「時數統計表」：插入兩欄的路線時數表格；填完後在表格上按右鍵「計算總時數」，自動加總所有「數字＋小時」，寫到表格下一行的「總共」。
- 右鍵選單：預設是貼上、插入台詞、時數統計表、圖片、摺疊清單、引用、複製這段的連結，可以在 設定 → 撰寫 → 右鍵選單（或選單最下面的「自訂這個選單…」）從所有動作裡勾選常用的、排順序、還原預設。看情況出現的項目會自動加在最上面：有選取文字時的剪下、複製、連結到文中段落；表格上的「計算總時數」；圖片上的併排。
- 所有右鍵選單（作品牆、作品、文章、編輯區、輸入框）在選單外面按滑鼠任一鍵、按 Esc、捲動、切換視窗都會關閉。對話框裡的文字框（例如 OCR 的辨識結果）右鍵是剪下／複製／貼上／全選。
- 選取文字後，工具列的「連結到段落」可以把文字連到文中任一段落，點連結就會捲過去。
- 貼上或拖入圖片會自動壓縮、轉檔（預設 WebP、最長邊 1920px），存進文章旁的 `assets/`。從網頁複製的圖片也會自動下載到本地。
- 撰寫時間：只計算視窗在前景、而且最近有輸入的時間（閒置判定時間可以調整）。按「完工」寫入完工日，計時同時暫停：只開著看、改屬性、看格式預覽都不算時間；之後真的修改內文才恢復計時，完工日也跟著更新。

**多格式版本**（編輯頁上方的「主稿｜Markdown｜巴哈｜FB｜串文｜Google 文件」）
- 點其他格式只會**預覽**從主稿即時轉出的結果，不會產生檔案；在那個格式裡開始修改（打字或調圖片）才會存成獨立版本，放在文章旁的 `variants/`（例如 `article.bahamut.txt`）。已建立的格式在分頁上有綠點。
- 建立後各自獨立，可以有不同排版。主稿之後有修改，打開該格式時會提示「重新產生（覆蓋這個版本）」或「保留目前版本」。
- 巴哈：照 bahamut-formatter 的規則輸出。段落用 `[div][size=3][color=#4D5156][bgcolor=#FFFFFF]`，小標題用 `size=5` 粗體，表格用微軟正黑體；置中和文字顏色保留原色碼。
  - 預覽用巴哈內文寬度（760px）排版。
  - 點預覽裡的圖片，可以設「原尺寸／大／中／小」，會在圖片後面加上 `width=`。大中小各是多寬，在「設定 → 圖片」調整。
  - 也可以按「與下一張併排」，兩張圖會放進同一個 `[div]`。
- FB：純文字，小標題變成【標題】，引用加「｜」，圖片位置標成〔圖1〕〔圖2〕，預覽模擬 FB 貼文和圖片排列，發文時照編號順序上傳。
- **串文**（Threads、X、Bluesky）：把主稿依平台字數上限拆成多則。
  - 上限：Threads 500、X 280（中日文每字算 2、網址算 23）、Bluesky 300。長段落會依句子拆開，標題和圖片盡量留在對的那一則。
  - 每個段落是一個方塊：可以按住左邊的 ⋮⋮ 拖到別則（會出現插入線）、用 ↑↓ 移動（移到頂或底會跨到相鄰那一則）、「⤓」從這個方塊開始拆成新的一則、「併入上一則」、「＋文字」新增方塊、× 刪除；文字也可以直接改。
  - 每則顯示字數／上限，超過會變紅。「複製這則」一次複製一則，複製過的會打勾變綠，方便照順序貼；結尾可選擇自動加「1/N」。圖片方塊上有「複製圖片」。
  - 存成 `variants/<檔名>.thread.json`，跟其他格式一樣，點進來只預覽，第一次搬動或修改才建立。
- Markdown：沿用主稿的 Markdown，最上面加標題。
- Google 文件：按「複製（含格式與圖片）」後到 Google 文件按 Ctrl+V，標題、粗體、顏色、置中、表格、圖片會一起貼上（圖片會先壓成 JPEG 一起放進剪貼簿）。
- 編輯格式版本的時間不算進撰寫時間。
- 巴哈與 FB 的圖片目前是文章資料夾內的相對路徑；接上 Cloudinary 圖床（第三階段）後會換成網址。

**Cloudinary 圖床**（設定 → 雲端）
- 填入你自己的 Cloudinary 帳號金鑰（Cloud name、API key、API secret）。按「儲存並測試」會先連線驗證，沒通過不儲存。API secret 用 Windows 加密後只存在這台電腦的使用者資料夾，**不會寫進文章庫**（文章庫可能被同步或分享），儲存後也不會再顯示。
- 編輯頁的「雲端」欄有「上傳到 Cloudinary」：先列出這篇有幾張圖、幾個文字檔、哪些已經在雲端略過，按了才上傳。設定裡勾選「按完工時詢問」，按「完工」時也會問一次（不會自己上傳）。
- 上傳什麼：這篇文章用到的圖片，加上文章本體、巴哈爬蟲的原始排版與資訊檔、各格式版本（`variants/`）。只傳有變的；重傳時沒變的略過，只改了標題就只更新雲端的名稱，不重傳圖片。
- 命名：雲端顯示名稱是「標題_圖1」「標題_圖2」…（依圖片在文中出現的順序，封面叫「標題_封面」）；實際檔名是 `makonote/<文章編號>/<原始路徑>`，編號不會變，所以改標題不影響還原。每個檔案的資料裡都記著它原本放哪個資料夾、哪個路徑、當時的 SHA-1。
- 上傳後，巴哈與 Markdown 版本的圖片可以一鍵「換成雲端網址」；新產生的版本直接用雲端網址。預覽仍然讀本機檔案。巴哈圖片網址要以圖片副檔名結尾，設定裡可選 webp 等格式轉成 jpg 輸出。
- 還原：設定 → 雲端 → 讀取清單，勾選文章、選一個資料夾，會照原本的資料夾結構把圖片和文章放回去，圖片回到文章引用的位置。已經存在的檔案一律不覆蓋，下載後會比對上傳當時的 SHA-1。雲端資料裡的路徑會當成不可信的輸入，超出還原資料夾的一律略過。
- 這個功能只用過本機模擬伺服器測試（會驗證簽章），沒有打過真的 Cloudinary；第一次用請先挑一篇圖少的文章試。

**美化（設定）**
- 背景圖、遮罩顏色與濃度、模糊、面板透明度、主色、圓角、字型、字級、行距、編輯區寬度。
- 編輯頁可以用這篇的作品封面當背景；背景跟著文章一起捲動，文章多長就鋪多長（圖片不夠長時上下鏡射接下去）。其他格式分頁（巴哈、FB…）的背景維持固定。
- 編輯頁右上角的「版面」按鈕：在編輯區右邊開一個面板（不蓋住文章），字型、字級、行距、編輯區寬度、背景圖、遮罩、模糊、面板透明度、圓角、主色都在裡面，邊寫邊調、立刻看到效果。開關會記住。
- 小貼圖：指定一個或多個圖片資料夾（直接讀取，不複製）。一次只顯示一張，固定在視窗左下或右下角，換頁時隨機換圖；位置可以設成隨機、固定右下或固定左下，也能開關、調整大小與透明度。只在空白處出現：貼圖位置底下有卡片或文字（文章多、畫面被填滿）就先藏起來，捲到空白或換頁再出現；也可以設定「列出的文章超過幾篇就不顯示」。
- 外觀可以存成主題（`.app/themes/`），搬到別台電腦也能用。
